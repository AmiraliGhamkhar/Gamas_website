# Redesign audit — before implementation

**Scope:** existing single-page Gamas landing page as inspected before UI changes. The user supplied the redesign specification after the repository scan; the repository itself had no `DESIGN.md`. The brief fixes the interactive blue (`#0066cc`), dark-surface link blue (`#2997ff`), radii scale, spacing and component vocabulary, but does not specify neutral surface values; those are recorded as explicit additions in `docs/design-decisions.md`.

| File/Component | Violation | DESIGN.md / brief rule | Fix |
|---|---|---|---|
| `src/index.css`, `tailwind.config.js`, `src/lib/constants.js` | Existing palette is near-black with indigo/violet/cyan, glass, gradients, glow and multiple hard-coded colors. | Use the brief's blue interactive tokens; no extra accent, decorative gradients, glows or untokenized colors. | Define one CSS token map, expose it through Tailwind, and remove legacy visual effects. |
| `src/index.css`, all section components | Glass classes blur and shadow many cards; several shadows are decorative. | Frost only the documented nav/sticky bars; no card/button/text shadows except the mirrored product-image shadow. | Make content cards flat; reserve frosted treatment for the sticky bars; apply the single image shadow in RTL. |
| `src/components/Hero.jsx`, headings throughout | Display type is Lalezar, but headings have tight Latin line-height/tracking; CTA uses weight 500. | Lalezar only for hero/tile headlines; Persian tracking zero, heading line-height 1.3–1.5; no 500. | Normalize heading scale/leading and weights; remove tracking. |
| `src/index.css`, `public/fonts/*`, `index.html` | A Vazirmatn 500 face is loaded; font preload points at local subsets but Latin coverage is delegated to fallback. | Self-host Vazirmatn Arabic + Latin and Lalezar Arabic; no weight 500; preload critical body font. | Use self-hosted package subsets with permitted weights and update preload; keep payload within budget. |
| `src/components/*` | Sections are mostly the same dark treatment; numerous glass/gradient cards instead of alternating full-bleed tiles. | Alternate light → dark → parchment → dark tiles, full bleed, with 80px rhythm (48px small phones). | Assign explicit tile variants and normalize responsive section padding. |
| `src/components/Hero.jsx`, `Navbar.jsx`, `Bento.jsx`, `FinalCTA.jsx`, `Preloader.jsx`, `LeadForm.jsx`, `FAQ.jsx`, `BotDemo.jsx` | Physical directional utilities/properties appear (`left-*`, `right-*`, `text-right`, offscreen `left`, `text-left`). | Use logical layout/alignment; directional motion and icons must follow RTL. | Convert to `start/end`, `text-start`, isolated honeypot styling and inline-start-aware transforms. |
| `src/components/HowItWorks.jsx` | Timeline animation grows from a hard-coded physical right origin. | Keep motion RTL-correct and reduced-motion safe. | Use the RTL inline-start edge with a logical percentage origin and refresh after fonts load. |
| `src/components/Navbar.jsx` | Drawer has `aria-expanded`, but no explicit Escape handling or focus containment/return. | Drawer enters from inline-start/right, traps focus, closes on Escape, and exposes expanded state. | Add keyboard behavior and safe focus restoration without changing navigation routes. |
| `src/components/LeadForm.jsx` | Field is visually hidden using a physical `left` offset; input messages can originate from server and lack field description association. | Preserve form names/API; label controls, set correct input mode, associate validation and announce status in Persian. | Keep endpoint/payload intact, use logical hidden styling, add `aria-describedby`/live error association and Persian fallback copy. |
| `src/components/*` | Many small text labels use 10–13px sizes; text contrast is muted on dark surfaces; several status treatments use unrelated hue accents. | Persian-small-text sizing/contrast and a single interactive accent. | Raise fine text where feasible, neutralize status colors and use AA-safe surface text tokens. |
| `src/components/Hero.jsx`, `FinalCTA.jsx`, `Footer.jsx`, `Navbar.jsx` | Telegram handle and mixed Latin/Persian text is inconsistently isolated; buttons often rely on hover styling. | Isolate Latin handles/URLs; no hover-only affordances; CTAs need active scale and visible focus. | Apply `<bdi dir="ltr">`, retain hover only as enhancement, define active/focus styles globally. |
| `src/components/*` | Some headings use 1.02–1.1 leading; body copy often uses 1.5–1.7; hero size does not follow the specified breakpoint steps. | Persian heading 1.3–1.5, paragraph ≥1.6, responsive hero 28/34/40/56px. | Establish semantic type tokens and fluid hero/title sizing. |
| `src/components/Preloader.jsx` | Full-screen dark overlay with mesh glows and a looping shimmer, delaying access to the rendered landing page. | No decorative effects; avoid blocking first paint and respect reduced motion. | Remove the redundant overlay; Vite SSG already serves the prerendered page immediately. |
| `src/components/*` | Several GSAP and CSS animations are present; reduced-motion checks exist in most animation components, but preloader/typing animation and timeline setup need consistent font refresh/reduced-motion behavior. | Respect reduced motion, preserve existing motion only where compliant, call `ScrollTrigger.refresh()` after fonts settle. | Centralize reduced-motion CSS behavior and refresh ScrollTrigger after `document.fonts.ready`. |
| `index.html` | Document is Persian/RTL, but `lang` is `fa`, and canonical/social URLs use root-specific metadata. There is no skip link or main-content target. | `lang="fa"`, RTL, theme-color, Persian SEO, canonical, semantic landmarks and skip link. | Preserve correct locale, align theme token, add skip navigation and stable metadata. |
| `src/components/Testimonials.jsx` | Empty state is present but its text is small/low contrast; it is presented as a card rather than a flat product tile. | Explicit empty state and flat component surfaces. | Keep honest empty-state content and restyle using the tile/card tokens. |

## Baseline

- `npm ci`: passed; zero vulnerabilities. npm emitted the existing `whatwg-encoding` deprecation notice.
- `npm run build`: passed (Vite client + SSG + postbuild checks); no build warnings.
- `npm run lint`: passed with zero warnings.
- `npm run dev`: started successfully on port 5173.
- No PHP endpoint, route, field name, environment variable, or request contract was changed during this audit.
